# Mẫu sitemap

Tạo file tại `docs/sites/<site>/sitemap.md`. Thay mọi `<...>`. Luật: `docs/conventions.md`.

````markdown
---
id: <site>-sitemap
type: sitemap
site: <site>
title: <host> Sitemap
description: "<Trang trả lời gì, tiếng Việt, <= 160 ký tự>"
description_en: "<Same in English, <= 160 chars>"
owner: hong
status: draft
version: 0.1
last_reviewed: YYYY-MM-DD
ai_readable: true
---

# <host> Sitemap

Nơi khai báo menu trong code: `<file>`.

```text
/ ............ <trang>
├── /<route>/  <trang>
└── /<route>/  <trang>
```

Footer: dải "Một phần của danghong.me".
````
