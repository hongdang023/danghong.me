# Mẫu content

Tạo file tại `docs/sites/<site>/content.md`. Thay mọi `<...>`. Luật: `docs/conventions.md`.

````markdown
---
id: <site>-content
type: content
site: <site>
title: <host> Content
description: "<Trang trả lời gì, tiếng Việt, <= 160 ký tự>"
description_en: "<Same in English, <= 160 chars>"
owner: hong
status: draft
version: 0.1
last_reviewed: YYYY-MM-DD
ai_readable: true
---

# <host> Content

| Nội dung | Mô tả | Nguồn dữ liệu | Trạng thái (Có / Mục tiêu / Link) |
| :--- | :--- | :--- | :--- |

Dữ liệu về Hồng đọc từ media.danghong.me, không giữ bản sao.
````
