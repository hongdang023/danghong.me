# PHASE C: IMPLEMENTATION (THỰC THI & VẬN HÀNH)

Quy chuẩn hóa việc lập trình và triển khai sản phẩm thực tế để đảm bảo tính ổn định và khả năng mở rộng.

---

## 1. DANH MỤC TÀI LIỆU (3 FILES)

1.  **[C1_Development_Standards](./C1_Development_Standards.md)**: Quy tắc lập trình, Git flow và kiểm tra tự động (CI).
2.  **[C2_Deployment](./C2_Deployment.md)**: Triển khai danghong.me, docs.danghong.me và media.danghong.me lên Cloudflare Pages.
3.  **[C3_Media_Library](./C3_Media_Library.md)**: Cách thêm/bớt thông tin, ảnh, video, link trên media.danghong.me và dùng lại ở các subdomain khác.

---

## 2. QUY TẮC CỐT LÕI

1.  **Type-Safe First**: Luôn ưu tiên TypeScript chặt chẽ.
2.  **Git-as-Truth**: Mọi thay đổi (code, tài liệu, media) phải được quản lý qua Version Control.
3.  **Continuous Improvement**: Liên tục Audit và Refactor code dựa trên tiêu chuẩn DAC.
