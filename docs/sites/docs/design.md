# docs.danghong.me Design

**Theme:** [danghong](../../ecosystem/design-system/themes/danghong.md) đặt lên VitePress default theme qua `docs/.vitepress/theme/custom.css`.

| Hạng mục | Giá trị |
| :--- | :--- |
| Font | Inter (mặc định của VitePress) |
| Màu nhấn | `#8E3A3A` (sáng), `#D98C8C` (tối) |
| Nền | `#F9F7F5` (sáng) |
| Dark mode | Có, theo VitePress |
| Trang chủ | Trang tài liệu thường với bảng "Tìm theo site", không dùng hero, để người và agent đọc như nhau |
| Sidebar | Nhóm: Bắt đầu, Hệ sinh thái, từng site, Quyết định & lịch sử |
