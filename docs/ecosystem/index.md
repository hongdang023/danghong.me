# Ecosystem — Shared Layer

Cái gì thuộc về **Hồng** hoặc **hạ tầng** thì viết một lần ở đây, mọi site đọc lại. Cái gì thuộc về **brand** hoặc **người đọc của brand** thì nằm trong `sites/<site>/`.

| Dùng chung (ở đây) | Riêng từng site (`sites/<site>/`) |
| :--- | :--- |
| Danh tính, bio, ảnh, liên hệ của Hồng | Audience và chân dung người đọc |
| Kiến trúc thương hiệu, quan hệ giữa các site | Theme đang dùng và ngoại lệ thiết kế |
| Lõi design system: lưới, breakpoint, truy cập, tên token, footer hệ sinh thái | Giọng văn, mục tiêu, chỉ số |
| Chuẩn viết nội dung (3S) | Sitemap, CTA chính |
| Yêu cầu phi chức năng, cổng kiểm | Loại nội dung và nguồn dữ liệu của site |
| Hạ tầng, DNS, dữ liệu D1/R2, deploy, quy chuẩn code | Cách deploy riêng, việc còn mở của site |
| Pháp lý: quyền riêng tư, cookie, bản quyền | Link tới nguồn sự thật của brand |
