# media — media.danghong.me

Code của media.danghong.me (Cloudflare Pages Functions). Nội dung nằm trong D1, file nằm trong R2; sửa tại [media.danghong.me/admin/](https://media.danghong.me/admin/).

```bash
npm install
npm run dev    # http://localhost:8788 (D1/R2 local)
npm test
```

Một file test: `node --test test/site.test.js`.

Hướng dẫn đầy đủ, route và JSON API: [docs/sites/media](https://docs.danghong.me/sites/media/ops) (`brief`, `sitemap`, `content`, `ops`).
